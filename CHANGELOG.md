# Changelog

All notable changes to AdSphere will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-07-08

### Added

- Initial project scaffold
- Monorepo setup with pnpm workspaces and Turborepo
- Backend: NestJS with Prisma ORM, Redis, JWT auth, WebSocket, BullMQ
- Frontend: Next.js with React, TypeScript, Tailwind CSS, Shadcn UI
- Authentication: Email/Password, Google, GitHub, Discord, 2FA
- Advertising System: Banner, Video, Popup, Interstitial, Reward, Native ads
- Campaign management with A/B testing, targeting, scheduling
- Payment integration: Stripe, Midtrans, PayPal, QRIS, Bank Transfer
- Real-time analytics dashboard
- Role-based access control (RBAC) + Attribute-based access control (ABAC)
- Docker containerization with CI/CD pipelines
- Comprehensive API documentation with Swagger
- Security: Helmet, rate limiting, CSRF, encryption, audit logging
- Testing setup with Jest, Playwright
